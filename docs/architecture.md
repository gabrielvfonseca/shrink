# ARCHITECTURE

TOKEN-COST IS A SMALL, DEPENDENCY-LIGHT CLI. THE PIPELINE HAS FOUR STAGES:
SCAN, TOKENIZE, ANALYZE, RENDER.

```
  path
   │
   ▼
┌──────────────┐   file list + skip records
│  scan.ts     │   (respects ignore files, filters noise)
└──────────────┘
   │
   ▼
┌──────────────┐   per-file token counts + line counts
│ tokenize.ts  │   (js-tiktoken, o200k_base, cached encoder)
└──────────────┘
   │
   ▼
┌──────────────┐   pareto stats, dir/file/ext aggregates,
│ analyze.ts   │   budget status
│ suggest.ts   │   ignore suggestions
└──────────────┘
   │
   ▼
┌──────────────┐   terminal report (rich text)
│ report/      │   JSON (machine-readable)
│  terminal.ts │   HTML (self-contained treemap)
│  html.ts     │
└──────────────┘
```

## THE TREEMAP ALGORITHM

`src/treemap.ts` IMPLEMENTS THE SQUARIFIED TREEMAP FROM BRULS, HUIZING, AND
VAN WIJK (2000).

FILES ARE SORTED BY DESCENDING TOKEN COUNT AND PLACED IN ROWS. A ROW IS GROWN
GREEDILY WHILE THE WORST ASPECT RATIO IN IT KEEPS IMPROVING, THEN THE ROW IS
LAID ALONG THE SHORTER SIDE OF THE REMAINING FREE RECTANGLE. THE RESULT HAS
ASPECT RATIOS CLOSE TO 1, WHICH IS WHAT MAKES THE CELLS READABLE AND THE
LABELS FITTABLE.

THE LAYOUT IS DETERMINISTIC — THE SAME INPUT ALWAYS PRODUCES THE SAME SVG.

## DESIGN DECISIONS

### NO NETWORK ACCESS

TOKEN COUNTS ARE COMPUTED LOCALLY WITH A BUNDLED ENCODER. NOTHING IS UPLOADED.
THIS MAKES THE TOOL USABLE ON PROPRIETARY CODE WITHOUT ANY COMPLIANCE REVIEW.

### SYNCHRONOUS TOKENIZATION, ASYNCHRONOUS IO

FILE READING AND DIRECTORY TRAVERSAL ARE ASYNC. TOKENIZATION IS SYNCHRONOUS
BECAUSE THE ENCODER IS A SHARED, CACHED, SINGLE-THREADED OBJECT — PARALLEL
TOKENIZATION WOULD JUST CONTEND ON THE SAME TABLE.

### AGGREGATION IN MEMORY

EVERY SCANNED FILE'S ENTRY IS KEPT IN MEMORY. FOR A TYPICAL REPOSITORY THIS
IS A FEW HUNDRED KILOBYTES. THE TREEMAP NEEDS THE FULL LIST TO LAY OUT
CELLS, AND THE AGGREGATES ARE DERIVED FROM IT IN ONE PASS.

### NO CLI FRAMEWORK

ARGUMENTS ARE PARSED WITH THE BUILT-IN `node:util` `parseArgs`. THE TOOL HAS
A HANDFUL OF FLAGS, AND A DEPENDENCY-FREE CLI STARTS FASTER AND INSTALLS
FASTER.
