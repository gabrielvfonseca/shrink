# GETTING STARTED

TOKEN-COST SHOWS YOU WHAT ACTUALLY EATS YOUR LLM CONTEXT WINDOW. POINT IT AT
A REPOSITORY AND IT TELLS YOU WHICH FILES ARE RESPONSIBLE, HOW MANY TOKENS
THEY COST, AND WHAT YOU CAN SAFELY IGNORE.

## INSTALL

RUN DIRECTLY WITH NPX — NO INSTALL NEEDED:

```sh
npx shrink
```

OR INSTALL GLOBALLY:

```sh
npm install -g shrink
```

REQUIRES NODE.JS 20 OR NEWER.

## FIRST RUN

SCAN THE CURRENT DIRECTORY:

```sh
npx shrink
```

SCAN A SUBDIRECTORY:

```sh
npx shrink ./src
```

THE HEADLINE TELLS YOU THE PARETO SHAPE OF YOUR REPO — HOW MANY FILES HOLD
MOST OF THE TOKENS:

```
  shrink · /Users/dev/my-repo

  Top 5 files = 61.4% of your context
  12 files = 50% · 31 files = 80%

  Total  184.2k tokens  · 412 files · 793.4KB
```

IF THAT NUMBER IS HIGH, YOUR CONTEXT WINDOW IS SPENDING MOST OF ITS BUDGET ON
A HANDFUL OF FILES. THE `SUGGESTED IGNORES` SECTION TELLS YOU WHICH ONES YOU
CAN DROP.

## SCREENSHOT-READY TREEMAP

THE HTML REPORT IS SELF-CONTAINED AND IDEAL FOR A README, ISSUE, OR SLACK
POST:

```sh
npx shrink --save-html report.html
```

OPEN IT IN A BROWSER. IT CONTAINS AN INTERACTIVE SQUARIFIED TREEMAP, TABLES
OF THE HEAVIEST FILES AND DIRECTORIES, PER-MODEL BUDGET STATUS, AND THE
SUGGESTED IGNORE PATTERNS.
