# TOKENIZATION

TOKEN COSTS ARE MEASURED WITH A REAL BPE TOKENIZER, NOT A CHARACTER ESTIMATE.

## THE ENCODING

COUNTS USE THE `o200k_base` ENCODING FROM `js-tiktoken`, THE SAME BPE FAMILY
USED BY THE GPT-4O GENERATION.

- EXACT FOR OPENAI MODELS THAT USE `o200k_base`
- A SOLID OFFLINE APPROXIMATION FOR CLAUDE, GEMINI, AND OTHER FAMILIES —
  TYPICALLY WITHIN ABOUT 10%
- FULLY OFFLINE — NO NETWORK CALLS, NO API KEYS, NO TELEMETRY

THE ENCODER IS LAZILY CONSTRUCTED ON FIRST USE AND THEN CACHED FOR THE
PROCESS LIFETIME. THIS KEEPS STARTUP FAST AND AVOIDS REBUILDING THE BPE TABLE
FOR EVERY FILE.

## WHY THIS MATTERS

A CHARACTER DIVISION BY FOUR IS A REASONABLE ROUGH ESTIMATE, BUT IT IS WRONG
BY ENOUGH TO MATTER WHEN YOU ARE DECIDING WHETHER A FILE FITS IN A CONTEXT
WINDOW. CODE IS FULL OF REPEATED IDENTIFIERS, INDENTATION, AND PUNCTUATION —
AND BPE PACKS THOSE INTO TOKENS VERY DIFFERENTLY THAN A FLAT CHARACTER COUNT
SUGGESTS.

COUNTING WITH THE REAL TOKENIZER MEANS THE TREEMAP AREAS AND THE PERCENTAGES
IN THE HEADLINE REFLECT WHAT YOUR MODEL WILL ACTUALLY SEE.

## CONTEXT WINDOW COMPARISON

THE REPORT COMPARES THE TOTAL AGAINST THE CONTEXT WINDOW OF EVERY KNOWN
MODEL AND LABELS EACH ONE:

- `fits` — AT OR BELOW 50% OF THE WINDOW
- `tight` — BETWEEN 50% AND 80%
- `over` — ABOVE 80%
- `unknown` — THE WINDOW SIZE IS NOT KNOWN

THE MODEL LIST LIVES IN `src/models.ts` AND COVERS THE CURRENT CLAUDE, GPT, GEMINI,
LLAMA, AND MISTRAL FAMILIES. ADDING A NEW MODEL IS A ONE-LINE ENTRY.

## THE PARETO HEADLINE

THE HEADLINE IS THE POINT OF THE TOOL:

```
Top 5 files = 61.4% of your context
12 files = 50% · 31 files = 80%
```

IT ANSWERS "HOW MANY FILES DO I ACTUALLY NEED?" — THE `FILES = 50%` AND
`FILES = 80%` FIGURES ARE THE EXACT COUNTS AT WHICH THE CUMULATIVE TOKEN
SHARE CROSSES THOSE THRESHOLDS, COMPUTED OVER FILES SORTED BY DESCENDING
TOKEN COUNT.

## ACCURACY NOTES

TOKEN COUNTS INCLUDE EVERYTHING IN THE FILE — COMMENTS, BLANK LINES, AND
WHITESPACE. THAT IS INTENTIONAL: AN AGENT READING THE FILE RECEIVES ALL OF
IT. THE `SUGGESTED IGNORES` FEATURE IS THE TOOL FOR DECIDING WHAT DOES NOT
DESERVE TO BE IN THE WINDOW IN THE FIRST PLACE.
