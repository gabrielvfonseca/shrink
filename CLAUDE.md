## WHAT THIS IS

`shrink` IS A CLI THAT MEASURES HOW MUCH LLM CONTEXT WINDOW A REPOSITORY
CONSUMES. IT SCANS A DIRECTORY, COUNTS TOKENS PER FILE, AND REPORTS THE
CONCENTRATION — "TOP 5 FILES = 60% OF YOUR CONTEXT" — ALONG WITH SUGGESTED
IGNORE PATTERNS.

IT IS A PUBLISHED NPM PACKAGE (`TOKEN-COST`) WITH A `TOKEN-COST` BIN. THE
RELEASED TARBALL CONTAINS ONLY `BIN/` AND `DIST/`.

## THE ONE RULE THAT MATTERS MOST

**NEVER SEND CODE ANYWHERE.** THE TOOL IS FULLY OFFLINE. IT COUNTS TOKENS
WITH A BUNDLED ENCODER, MAKES NO NETWORK CALLS, AND HAS NO TELEMETRY. DO NOT
ADD A REMOTE CALL, A FETCH, AN UPLOAD, OR AN ANALYTICS BEACON. THIS IS THE
PROMISE THAT MAKES THE TOOL USABLE ON PROPRIETARY CODE.

## COMMANDS

```sh
npm run lint          # BIOME CHECK
npm run check:fix     # ULTRACITE FIX (SAFE FIXES)
npm run typecheck     # TSC --NOEMIT
npm run build         # TSC -> DIST/
npm test              # VITEST
npm run changeset     # CREATE A CHANGESET
```

THE PRE-COMMIT HOOK RUNS `LINT-STAGED`, WHICH FORMATS AND LINTS STAGED FILES
AUTOMATICALLY. A GENUINE LINT ERROR BLOCKS THE COMMIT.

## ARCHITECTURE

THE PIPELINE IS FOUR STAGES:

```
SCAN (src/scan.ts) -> TOKENIZE (src/tokenize.ts) -> ANALYZE (src/analyze.ts, src/suggest.ts) -> RENDER (src/report/)
```

- `src/scan.ts` — DIRECTORY WALK. HONOURS `.gitignore`, `.tokenignore`, AND
  `.ignore` AT EVERY LEVEL, PLUS A BUILT-IN NOISE DENYLIST. SKIPS BINARIES,
  EMPTY FILES, SYMLINKS, AND OVERSIZED FILES.
- `src/tokenize.ts` — `js-tiktoken` WITH THE `o200k_base` ENCODING. THE
  ENCODER IS CACHED AND LAZILY CONSTRUCTED. EXACT FOR GPT-4O FAMILY, ~10%
  APPROXIMATION FOR OTHERS.
- `src/treemap.ts` — SQUARIFIED TREEMAP LAYOUT (BRULS, HUIZING, VAN WIJK).
  DETERMINISTIC: THE SAME INPUT ALWAYS PRODUCES THE SAME SVG.
- `src/analyze.ts` — PARETO STATISTICS, AGGREGATION BY DIRECTORY AND
  EXTENSION, PER-MODEL BUDGET STATUS.
- `src/suggest.ts` — HEURISTIC IGNORE SUGGESTIONS. FIRST MATCHING RULE WINS
  PER FILE, SO SAVINGS NEVER DOUBLE-COUNT.
- `src/report/terminal.ts` — COLOUR-CODED TEXT REPORT.
- `src/report/html.ts` — SELF-CONTAINED HTML REPORT WITH AN INLINE SVG
  TREEMAP. NO CDN, NO EXTERNAL ASSETS, NO ANALYTICS.

## CONVENTIONS

- ESM ONLY. `"TYPE": "MODULE"`, `.JS` EXTENSIONS IN RELATIVE IMPORTS.
- `NODE:` PREFIX FOR BUILTINS.
- TYPES LIVE IN `SRC/TYPES.TS`. NO `ANY` — USE `UNKNOWN` AND NARROW.
- TESTS LIVE IN `TESTS/`, NAMED AFTER THE MODULE THEY COVER
  (`TESTS/SCAN.TEST.TS` FOR `SRC/SCAN.TS`).
- DOCUMENTATION LIVES IN `DOCS/` WITH `SNAKE_CASE` FILENAMES AND UPPERCASE
  CONTENT. SEE `DOCS/DEVELOPMENT.MD`.
- THE CLI USES `NODE:UTIL` `PARSEARGS`, NOT A CLI FRAMEWORK. KEEP DEPS SMALL.

## WORKING ON THIS REPO

- ADD A CHANGESET FOR ANY USER-FACING CHANGE. `MAJOR` FOR BREAKING CLI OR
  JSON SCHEMA CHANGES, `MINOR` FOR NEW FEATURES, `PATCH` FOR FIXES.
- NEVER EDIT `PACKAGE.JSON`'S `VERSION` FIELD BY HAND. CHANGESETS OWNS IT.
- NEVER RUN `CHANGESET PUBLISH` LOCALLY. IT IS IRREVERSIBLE AND CI-DRIVEN.
- NEVER COMMIT OR PUSH WITHOUT ASKING.
