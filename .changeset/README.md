# Changesets

This folder has been automatically generated by `@changesets/cli`. Changesets
keep a changelog and bump the package version in lockstep with your commits.

## Adding a changeset

```sh
npm run changeset
```

Pick the bump type (`patch`, `minor`, `major`), write a one-line summary, and
commit the generated markdown file alongside your code. Every changeset file in
this folder is consumed by the release workflow.

## Releasing

```sh
npm run changeset:version   # apply changesets, bump version, update CHANGELOG
npm run changeset:publish   # publish to npm
```

Both are normally driven by `.github/workflows/release.yml`, which opens a
"Version Packages" pull request and publishes once that PR is merged.
